5. **app.py** — Update XGBoost dmat to 8-feature vector for ESP/Mud Pump; add `amps`/`spm` chart metric
6. **index.html** — Add conditional 4th sensor tab (ESP → "Motor Current", Mud Pump → "Stroke Rate")
7. **Deploy** 3 containers: fault-trigger-ui, telemetry-simulator, event-processor

## Build + Deploy Pattern

```bash
cd /home/brian/gdc-pm
REG="us-central1-docker.pkg.dev/gdc-pm-v2/gdc-models"

# fault-trigger-ui (app.py + new models)
docker build --quiet -t "${REG}/fault-trigger-ui:latest" gke/fault-trigger-ui/ && \
  docker push --quiet "${REG}/fault-trigger-ui:latest" && \
  kubectl rollout restart deployment/fault-trigger-ui -n gdc-pm && \
  kubectl rollout status deployment/fault-trigger-ui -n gdc-pm --timeout=120s

# telemetry-simulator
docker build --quiet -t "${REG}/telemetry-simulator:latest" gke/telemetry-simulator/ && \
  docker push --quiet "${REG}/telemetry-simulator:latest" && \
  kubectl rollout restart deployment/telemetry-simulator -n gdc-pm && \
  kubectl rollout status deployment/telemetry-simulator -n gdc-pm --timeout=120s

# event-processor
docker build --quiet -t "${REG}/event-processor:latest" gke/event-processor/ && \
  docker push --quiet "${REG}/event-processor:latest" && \
  kubectl rollout restart deployment/event-processor -n gdc-pm && \
  kubectl rollout status deployment/event-processor -n gdc-pm --timeout=120s
```
